# Лабораторная работа № 3 — Доска публикаций

## Способ запуска
1. Распакуйте архив
2. Откройте `index.html` в браузере

## Тесты
1. Нажатие «Загрузить публикации» | 5 записей с заголовком и текстом
Пустые поля или одни пробелы | ошибка валидации, запрос не отправляется
Корректный заголовок и текст | HTTP 201, публикация появляется, показан ID
Нет сети | сообщение об ошибке, кнопка снова активна
